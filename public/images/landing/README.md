# Landing carousel illustrations

Original conceptual illustrations generated with the built-in `image_gen` tool for Meatualiza. They depict reasoning and learning metaphors, not the real tutoring venue. The [sign-in illustration](../sign-in-illustration.webp) was used only as a reference for materials, lighting, and palette.

The generated PNGs were resized to 1200 pixels wide and converted to WebP at quality 85 without changing the composition.
