# Google artwork

`google-g.png` is the unmodified Google G artwork supplied in the
[Sign in with Google branding guidelines](https://developers.google.com/identity/branding-guidelines).

Source: <https://developers.google.com/static/identity/images/g-logo.png>

The asset retains Google's brand colors. The surrounding interface uses the
application's neutral theme; the OAuth button uses the approved neutral palette.
